One word from your ex: **unread**. The word is the last text she sent, still sitting unread as a monument — he never read her messages, and she never really read him. One word, two indictments.

## Run it

```sh
python3 main.py
```

Writes exactly `unread` to `/output/entry.txt`. Deterministic: no randomness, no clock, no network, no input — run it twice and the output is byte-identical.
